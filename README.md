# AS VK

Нативное приложение ВКонтакте для Android в стиле **MultiTool Black Gold**.
Экраны — системные (Java, ListView, MediaPlayer), без WebView для контента.
WebView используется только один раз: на входе, где ВК показывает свою страницу.

Автор: **AethernalSoul**.

## Установка

1. Скачай `ASVK-1.0.apk` из **Releases**.
2. Открой на телефоне, разреши установку из этого источника.
3. «Войти через VK» → войди в аккаунт → приложение откроется само.

Android 7.0+ (minSdk 24), targetSdk 35.

## Что внутри

- **Чаты** — список диалогов с аватарами и непрочитанными, переписка, отправка сообщений;
- **Музыка** — список треков, воспроизведение через MediaPlayer, уведомление с управлением
  (плей/пауза/следующий), работа в фоне, долгий тап — скачать трек в кэш;
- **Сообщества** — список групп;
- **Профиль** — аккаунт, очистка кэша, выход;
- тема Black Gold: фон `#0a0a0c`, акцент `#d4af37`.

Рекламы нет: интерфейс свой, рекламные блоки ВК не загружаются.

## Как устроен вход

Нативное окно → кнопка «Войти через VK» → страница ВК (WebView) → после входа приложение забирает
токен веб-сессии из localStorage ВК и дальше работает уже без WebView. Токен хранится локально
в SharedPreferences.

## Сборка

Без Gradle: `aapt2 → javac → R8 → zipalign → apksigner`.
Запуск: `powershell -ExecutionPolicy Bypass -File build.ps1`.
Итог: `out/ASVK-1.0.apk`.
