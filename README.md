# AS VK

Кастомизатор ВКонтакте в стиле **MultiTool Black Gold**.
Внутри — ВК, снаружи — наш сайдбар и навигация: Чаты, Музыка, Сообщества, Лента, Профиль.
Вход обычный, через VK ID: логин/пароль на странице ВК, без регистрации приложений и токенов.

Автор: **AethernalSoul**.

## Установка (Android)

1. Скачай `ASVK-1.0.apk` из раздела **Releases**.
2. Открой файл на телефоне.
3. Разреши установку из этого источника.
4. Запусти «AS VK» и войди в аккаунт.

Требования: Android 7.0+ (minSdk 24).

## Что внутри

- нижняя навигация: Чаты, Музыка, Сообщества, Лента, Профиль;
- тема Black Gold на всех страницах: фон `#0a0a0c`, акцент `#d4af37`;
- реклама скрыта: CSS-правила + скрипт + блокировка рекламных доменов;
- музыка — штатный плеер ВК, играет в фоне.

## ПК

Windows-версия собирается из `vk-client` (Electron): наш сайдбар + контент ВК.
Готовый файл — `AS-VK-1.0.0.exe`, портативный, ничего не устанавливает.

## Ограничения

- Это оболочка над ВК: контент рендерит сам ВК, мы даём навигацию, тему и чистку рекламы.
  Полностью свой рендер ленты/чатов требует API-приложения ВК.
- Офлайн-скачивания музыки нет: у ВК нет бесплатной загрузки.
