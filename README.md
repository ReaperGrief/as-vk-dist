# AS VK

Клиент ВКонтакте для Android в стиле **MultiTool Black Gold**.
Открывает настоящий ВК и даёт войти своим логином — без токенов и регистрации приложений.
Тема применяется на каждой странице, рекламные блоки скрываются.

Автор: **AethernalSoul**.

## Установка

1. Скачай `ASVK-1.0.apk` из раздела **Releases**.
2. Открой файл на телефоне.
3. Разреши установку из этого источника (Настройки → Безопасность → Неизвестные источники).
4. Запусти «AS VK» и войди в аккаунт.

Требования: Android 7.0+ (minSdk 24).

## Что внутри

- WebView-оболочка над `m.vk.com`;
- тема Black Gold: фон `#0a0a0c`, акцент `#d4af37`;
- вырезание рекламы: CSS + скрипт, блокировка рекламных доменов;
- музыка играет штатным плеером ВК, в том числе в фоне.

Офлайн-скачивания музыки нет: у ВК нет бесплатной загрузки, обход DRM не поддерживается.

## Что учесть

- Если ВК не пустит логином внутри WebView — используй вход по QR-коду.
- Приложение не связано с ВКонтакте и распространяется как есть, для личного использования.

## Сборка

Исходники собираются без Gradle: `aapt2 → javac → R8 → zipalign → apksigner`.
