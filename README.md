# AS VK

Свой клиент ВКонтакте в стиле **MultiTool Black Gold**: интерфейс наш, данные — из VK.
Вход обычный, через страницу ВК (логин, пароль или QR). Регистрация приложений и токены вручную не нужны.

Автор: **AethernalSoul**.

## Установка

### Android
1. Скачай `ASVK-1.0.apk` из раздела **Releases**.
2. Открой файл на телефоне, разреши установку из этого источника.
3. Запусти «AS VK» → «Войти через VK» → войди в аккаунт.

Android 7.0+ (minSdk 24).

### Windows
Портативный `AS-VK-1.0.0.exe` — запускается двойным кликом, ничего не устанавливает.

## Что внутри

- **Новости** — лента с фото и вложениями;
- **Сообщения** — диалоги, история, отправка, отметка о прочтении, обновление в реальном времени;
- **Друзья** — список с онлайном;
- **Музыка** — список треков, проигрывание, скачивание в кэш (IndexedDB), офлайн и фон;
- **Профиль** — аккаунт, кэш, выход;
- тема Black Gold: фон `#0a0a0c`, акцент `#d4af37`;
- рекламы нет: интерфейс свой, рекламные блоки ВК не рендерятся.

## Как устроен вход

Приложение открывает страницу ВК. После входа оно берёт токен, который веб-ВК сохранил в вашем
профиле на этом устройстве, и работает с ним. Токен остаётся на устройстве, третьим лицам не передаётся.
Если он истёк — достаточно снова нажать «Войти через VK».

## Сборка

- Windows: `npx electron-builder --win portable` в `vk-client`.
- Android: `build.ps1` (aapt2 → javac → R8 → zipalign → apksigner), без Gradle.
